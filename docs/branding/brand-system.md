# Brand System

SuperNova should communicate trust, movement, safety, intelligence, premium quality, and calm confidence without imitating Uber, DiDi, Bolt, or inDrive.

The Phase 0 brand gate uses a precise abstract nova core with directional negative space. The symbol is built from two restrained motion fields and a centered nova aperture, creating controlled energy, navigation, trust, precision, and premium technology without using a literal car, route pin, explosion, or decorative orbit.

## Logo System

The source of truth lives in `packages/design-tokens/assets/brand/`.

- `supernova-symbol.svg`: primary color symbol.
- `supernova-wordmark.svg`: path-based wordmark.
- `supernova-lockup-horizontal.svg`: default lockup.
- `supernova-lockup-stacked.svg`: stacked lockup.
- `supernova-symbol-monochrome.svg`: one-color symbol.
- `supernova-symbol-white.svg`: white symbol.
- `supernova-symbol-black.svg`: black symbol.
- `supernova-app-icon.svg`: app icon source.

No alternate logo masters should be committed in app folders. Platform PNG, ICO, and store exports must be generated from these SVG sources when the release pipeline needs raster outputs.

## Personality

SuperNova is calm, precise, safety-led, human-centered, transparent, efficient, and reliable. Visual decisions should feel premium and controlled, not playful, gaming-like, crypto-like, browser-like, VPN-like, or AI-assistant-like.
