# Rider Navigation

Rider navigation is a single primary task path with safety access always visible. The prototype uses in-memory state and no production route guards.

Primary path: splash, language, onboarding, phone, OTP, location, map home, destination search, pickup, vehicle, fare, searching, assigned, arriving, arrived, QR/PIN, active trip, safety/share, completed, payment, rating, history, profile.

RTL behavior mirrors back direction, map controls, bottom-sheet alignment, and tab order.
